# Java Compute Engine

Reference Java test app that mirrors `test/apps/rust_runner/`. Used
by the shared conformance suite under `FLEZHA_E2E_RUNTIME=java mix test
--include system` and by the `mix bench --runtime java` regression bench. The
factory ids it registers, the transports it supports and how it is launched are
declared in `conformance.json` beside this file — see
`docs/sdk/conformance.md`.

The app declares its UnboundedOperator classes via
`Flezha.createRunner(ns).registerFactory(...)` — the integration-matrix core
being:

- `do_nothing` — `DoNothingUnboundedOperator` + `DoNothingTasklet`
- `store_input` — `StoreInputUnboundedOperator` + `StoreInputTasklet`
- `compare_filter` — `CompareFilterUnboundedOperator` + `CompareFilterTasklet`

The factory id list matches `test/apps/rust_runner/`'s `do_nothing` /
`store_input` / `compare_filter` set; the `operator-message-handlers`
factories are absent from both apps until that capability ships.

It also carries the §5 short forms (`@UnboundedOperator` / `@BoundedOperator`, generated by
`flezha-sdk-processor`): `SugarDoNothing`, `SugarStore`, `SugarNamedInput`, the sinkless
`SugarStateOnly`, the bounded short forms `SugarBounded` and the `per_input`
`SugarBoundedPerInput`; and the 2-tasklet `SugarEntry` → `SugarDownstream` reference operator
(`@Tasklet` / `@State`, wired by `SugarStaticCellUnboundedOperator`). `Main` registers each short
form by the class it wrote with `registerFactory`, as it registers every hand-written operator;
`SugarTwinTest` asserts they register and process input identically to the hand-written
equivalents. See `docs/sdk/authoring_contract.md`.

## Build

```sh
mvn -f test/apps/java_runner/pom.xml package
java -jar test/apps/java_runner/target/java_runner.jar my_namespace
```
